# Multimodal Semantic Search (image + audio)

This project provides CLIP text-to-image search and additive CLAP text-to-audio
search. Image search remains available with `--media image`; audio uses a
separate model and FAISS index.

## Setup

```bash
python -m pip install -r requirements.txt
```

CLIP and CLAP checkpoints are separate downloads. The first image embedding
downloads OpenCLIP `ViT-B-32` OpenAI weights. The first audio embedding
downloads the `laion_clap` checkpoint. Audio is loaded as mono and resampled
to CLAP's expected 48 kHz rate.

Add 15–20 real images under `data/sample/images/` and 10–15 short audio clips
under `data/sample/audio/`. Use varied subjects: animals, food, landscapes,
and objects for images; music genres, animal sounds, ambient noise, and speech
for audio. Real media is not generated by this scaffold. [Freesound](https://freesound.org/)
is a useful source for freely licensed short clips; check each clip's license.

## Indexing and search

```bash
python -m src.index_images --source data/sample/images/
python -m src.index_audio --source data/sample/audio/
python -m src.search --query "a dog running" --media image --k 5
python -m src.search --query "dog barking" --media audio --k 5
python -m src.search --query "a dog running" --media both --k 5
```

Indexes are independent: `faiss_index/images.index` and
`faiss_index/audio.index`, with separate metadata sidecars. Both indexers
track SHA-256 hashes, skip unchanged files, append new files, and rebuild when
files change or disappear. Use `--force` to re-embed all files.

The original image paths (`data/index.faiss` and `data/metadata.json`) remain
readable by the search CLI as a compatibility fallback. Custom paths are
available through `--index-path` and `--metadata-path`.

## Why CLIP and CLAP scores cannot be merged

CLIP learns an image-text space, while CLAP learns an audio-text space. Each
model's contrastive training defines its own coordinate system, dimensionality,
scale, and score distribution. A CLIP cosine score and a CLAP cosine score may
both be called “semantic similarity,” but they are similarities within
different learned spaces. Their numeric values are not calibrated against one
another, so averaging, subtracting, or globally ranking them is meaningless
without a separately trained cross-modal alignment model.

With `--media both`, the query is encoded independently by CLIP and CLAP, and
the CLI prints two labeled result lists. It deliberately does not merge or
compare scores across those lists. Within either list, L2 normalization plus
FAISS `IndexFlatIP` gives cosine similarity because normalized vectors have
unit length, making their inner product equal to cosine similarity.

## API and UI

Start the FastAPI service and Streamlit frontend in separate terminals:

```bash
uvicorn src.api:app --reload
streamlit run app.py
```

The API serves indexed sample and uploaded media under `/media/sample` and
`/media/uploads`. Uploads are embedded and appended to the matching FAISS
index immediately; no full reindex is performed.
